# Goblin Chat Gallery

Create 120 chatbots where each bot is a different goblin. You should be able to scroll through and pick the goblin you want to talk to. The goblins should only reference in-universe content from themselves and the other goblins. They should make references to the other goblins, but don't make up any new goblins

This project was built with [Lovable](https://lovable.dev).
